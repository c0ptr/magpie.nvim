*magpie.nvim*             Translate words and Visual selections in Neovim

==============================================================================
Contents                                                           *magpie*

  1. Setup ................................................ |magpie-setup|
  2. Commands ............................................. |magpie-commands|
  3. Mappings ............................................. |magpie-mappings|
  4. Configuration ........................................ |magpie-config|

==============================================================================
1. Setup                                                       *magpie-setup*

Requires Neovim 0.10+ and curl; network access is only needed for text
outside the bundled dictionary and cache.  With lazy.nvim: >lua
  {
    "your-name/magpie.nvim",
    main = "magpie",
    opts = {},
  }
<
The default target language is zh-CN and the default provider is Google.
Available providers: Google, Bing (Azure), DeepSeek, and Youdao.
The plugin creates a non-focusable native floating window showing the source
text, IPA pronunciation (for English words), and translation.

==============================================================================
2. Commands                                                *magpie-commands*

                                                        *:Magpie*
:Magpie [text]  Translate [text].  Without an argument, translate the
                       Visual selection or the word under the cursor.

                                                   *:MagpieClose*
:MagpieClose    Close the result floating window.

==============================================================================
3. Mappings                                                *magpie-mappings*

                                                        *<leader>tw*
<leader>tw in Normal mode translates the word under the cursor.  In Visual mode
it translates the selected word or sentence.  Set `keymaps.normal = false` or
`keymaps.visual = false` to omit either built-in mapping.

With `hover.enabled = true` (the default), hovering a word with the mouse
translates it after `hover.delay_ms`.  Neovim's 'mousemoveevent' option is
enabled for this.  With `mouse_selection.enabled = true`, a Visual selection
made by mouse drag is translated when the mouse button is released.

==============================================================================
4. Configuration                                           *magpie-config*

>lua
  require("magpie").setup({
    target_lang = "zh-CN",
    source_lang = "auto",
    provider = "google", -- "google", "bing", "deepseek" or "youdao"
    hover = { enabled = true, delay_ms = 550 },
    mouse_selection = { enabled = true },
    cache = { persist = true, max_disk_entries = 500 },
    local_dictionary = { enabled = true },
    keymaps = { normal = "<leader>tw", visual = "<leader>tw" },
  })
<

Google uses its public web endpoint by default.  For the official Google Cloud
Translation Basic v2 API, set `google.api_key` or $GOOGLE_TRANSLATE_API_KEY.

Bing uses Azure Translator.  Set `provider = "bing"` and provide
`bing.api_key` or $AZURE_TRANSLATOR_KEY.  $AZURE_TRANSLATOR_REGION is used when
needed by the Azure resource.

DeepSeek uses an LLM chat API.  Set `provider = "deepseek"` and provide
`deepseek.api_key` or $DEEPSEEK_API_KEY.  Youdao needs `provider = "youdao"`
with `youdao.app_key`/`youdao.app_secret` or $YOUDAO_APP_KEY/$YOUDAO_APP_SECRET.

A bundled list of the ~2000 most common English words is checked before any
network request when `local_dictionary.enabled = true` (default) and
`target_lang` starts with "zh".  With `cache.persist = true` (default),
covered and previously translated text works offline.  Cache files live in
|stdpath()| "data"/magpie/.
